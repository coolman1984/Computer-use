# SmartOps Tab Bridge

Load this folder as an unpacked Chrome extension. Click its toolbar icon on the
one tab you want to share; the red `ON` badge means SmartOps can read that tab's
visible control structure. Click again to stop.

It has temporary `activeTab` access only. It does not read field values,
password controls, cookies, browser storage, network bodies, or downloads.
Snapshots stay in core memory and disappear when the server stops.
