Step 1 · Add the system

A system is one website plus the reports you collect from it. Everything else hangs off it: you sign in to a system, you record against a system, and every run and file belongs to one.

Definitions are saved as files in your systems folder. You can edit them here or by hand — both read the same files, and changes take effect immediately with no restart.
