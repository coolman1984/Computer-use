What a system is

A system is one target site plus the reports you collect from it. Everything else in SmartOps keys off a system: you sign in to a system, you record a workflow against a system, and every run and file belongs to one. Systems are defined in YAML files, never in this interface, so that no internal URL or selector is ever stored in the app database.

SmartOps reads them from the configured systems directory. Point SMARTOPS_SYSTEMS_DIR at a private folder outside the repository, put one .yaml file per system in it, and restart the server.
