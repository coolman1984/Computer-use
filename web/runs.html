How runs start

A run is one execution: collecting a report, or a platform check. The normal way to start one is Collect now on a report in Systems — that fills in the system, report, validation rules, and alert thresholds for you. Runs also start on their own from each report's schedule.

Start a workflow by key (advanced)

For platform workflows and debugging. platform.selfcheck needs no parameters; collect.report needs the full parameter set that Collect now builds automatically.
