Two ways to sign in

Session (recommended, and required for SSO): you sign in yourself once in a real browser window, and SmartOps saves the resulting session so later runs reuse it. Your password is never seen by the platform. This is the only mode that works when sign-in goes through an interactive SSO popup, MFA, or a corporate identity provider.

Unattended: for plain username/password forms only. You store the credential once below, and SmartOps types it into the login form itself. It cannot handle SSO popups or MFA.

Which mode a system uses is set by auth.mode in that system's YAML file — it is not switchable from here.
