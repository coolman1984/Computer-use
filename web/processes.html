Steps 6 to 10 · From a recording to something that runs by itself

An automation is a recording that has been turned into something the platform can repeat. It moves through four gates, and each one is enforced — you cannot skip a step:

  1. Test it — it runs once, for real, against the real system.
  2. Approve it — only offered after a test passes. This is your go-ahead for it to run without you watching.
  3. Run it — on demand, any time.
  4. Schedule it — only for something already approved.
