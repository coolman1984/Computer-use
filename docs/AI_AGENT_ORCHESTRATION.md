# إدارة وكلاء الذكاء الاصطناعي

## الهدف

تشغيل Codex CLI وClaude Code CLI كعمال خلفيين منظمين، وليس كأدوات مستقلة عشوائية.

## مستويات المهمة

### قراءة فقط
تحليل السجلات والكود والحوادث بدون تعديل.

### تجربة
إنشاء نسخة عمل، تعديلها، وتشغيل الاختبارات.

### تنفيذ
نشر إصلاح نجح في الاختبارات وسمحت به السياسة.

## التصعيد

```text
حل ثابت معروف
↓
وكيل اقتصادي
↓
Codex تفكير متوسط
↓
Codex تفكير مرتفع
↓
Claude أقوى
↓
إنسان
```

يجب أن يكون التصعيد مبنيًا على:
- نوع المشكلة.
- المخاطر.
- عدد المحاولات.
- تاريخ الحلول.
- درجة الثقة.
- تكلفة الوقت والحوسبة.

## حزمة السياق للوكيل

لا ترسل "حدث خطأ" فقط.

أرسل:
- وصف المهمة.
- سجل التشغيل.
- الخطوة الفاشلة.
- لقطة الشاشة.
- تتبع المتصفح.
- النسخة الحالية.
- آخر تغييرات.
- تشغيلات ناجحة مشابهة.
- حلول سابقة.
- الاختبارات المطلوبة.
- حدود الصلاحيات.

## سجل الوكيل

لكل تشغيل وكيل:
- من استدعاه.
- لماذا.
- النموذج.
- مستوى التفكير.
- الملفات المقروءة.
- الأوامر.
- الملفات المعدلة.
- الاختبارات.
- النتيجة.
- زمن التنفيذ.
- التصعيد التالي إن وجد.

## الحماية

- لا تعديل مباشر على الإنتاج دون سياسة.
- لا حذف بيانات.
- لا تغيير صلاحيات.
- لا لمس أسرار.
- أي تعديل يجب أن يكون قابلًا للتراجع.
